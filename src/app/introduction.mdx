# Open Rainbow UI

Shared components for the Open Rainbow website.

- Use the **theme** switch in the toolbar to see each component in light and dark.
- All copy comes from the JSON files in `public/data`. Stories load the same files.
- Colours come only from the theme tokens in `src/styles.scss`. Tailwind utilities
  (for example `bg-surface`, `text-ink`, `border-line`) use the same tokens.
